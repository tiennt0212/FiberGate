# Maintainers

FiberGate is currently maintained by a single maintainer,
[@tiennt0212](https://github.com/tiennt0212), who reviews and merges all pull
requests.

For the day-to-day mechanics of maintaining this project — publishing releases
(`fibergate-core`'s Docker image, the `create-fibergate` and `@fibergate/sdk` npm
packages), and how architecture/business decisions get recorded — see
[docs/maintainers/release-process.md](docs/maintainers/release-process.md) and
[docs/maintainers/getting-started.md](docs/maintainers/getting-started.md).

Contributors: see [CONTRIBUTING.md](CONTRIBUTING.md).
